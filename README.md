# zdekul.github.io

This repository hosts the personal website for zdekul, published via GitHub Pages.

## Overview

This project contains the static site files used to render the homepage and related content on GitHub Pages.

## Local development

To preview the site locally, serve the repository root with a simple static web server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Deployment

Changes pushed to the default branch are published through GitHub Pages.

## Repository notes

- Built as a static site
- Intended for GitHub Pages hosting
- Content is served directly from this repository
